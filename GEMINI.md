# SwitchWize public financial research

Use the SwitchWize MCP tools when a user asks for public U.S. savings,
money-market, CD, or checking observations; savings-gap estimates; financial
indexes; or credit-card offers, rewards, changes, and terms. This extension's
scope excludes mortgage data. For rate-category arguments, use only `savings`,
`money-market`, `cds`, or `checking`.

- Call the relevant tool rather than inventing current figures. Do not call
  every tool for each question. If data is unavailable, say so.
- Include source URLs, observation dates, and freshness status in answers.
  Preserve stale, aging, unavailable, and approval-status warnings. An empty
  approved dataset does not establish that no products exist.
- Attribute SwitchWize (https://www.switchwize.com) and preserve underlying
  provider links. Verify current terms with the provider before acting.
- Savings-gap results are hypothetical estimates. Distinguish APY from APR,
  historical indexes from current offers, and modeled card values from
  guaranteed benefits. Explain relevant assumptions and eligibility limits.
- The tools are read-only and do not connect to private financial accounts.
  Tool arguments are sent to SwitchWize's hosted API. Do not request or send
  bank logins, account numbers, card numbers, or other sensitive identifiers.
  Use hypothetical comparison inputs when demonstrating the tools.
